# 遥控连续转向、触感反馈与建图步骤统一计划

日期：2026-10-24（Asia/Shanghai）。状态：本地实施及离线验收完成，实机/ROS联调未执行。上一版整车零速等待/提前结束策略已回退；保留独立诊断测试并重做单轮过零控制。未部署。

磨盘补充：用户只是确认启动规则，并未要求更改。进入遥控页只读；当前转速提交无论是否0均写disc_enabled=true；板端另有行走启磨盘/停车关闭联动。暂不改变磨盘使能规则。

## 已核实的问题

- 上一版改法仍然先将整车轮速清零，再通过零速反馈提前结束等待；它只缩短停顿，不能作为连续转向的最终方案。该版本仅在本地，未部署。
- 新混控在前进档内也可能令内侧轮反向，旧保护按任意单轮符号翻转触发整车停车。驱动 YAML 当前关闭轮速斜坡，不能只删除调度保护。
- APP 当前未找到现成的触感反馈实现。触感应表达操作受理，不代表板端已确认运动。
- Step1 缩放1–8，Step2/3为0.5–6；Step1视口在局部remember中，进入新Step2会话重新建立默认zoom/pan，没有传递视角。
- Step1外边距12dp，Step2水平24dp；导航按钮分别160×44dp与200×56dp。取消按钮颜色、文字图标、底部高度不同；Step2未复用GlobalTopBar。这些都会造成切步时的位置和比例跳变。

## 1. 连续转向控制重做（本地完成）

- 继续满足前后目标速度=设定速度×(1-|转向行程|)，默认转向力度70%，满杆目标为原地转向。
- 区分车辆前后操作换向、差速转向中的单轮过零，以及停止/急停。前进中拉方向，不再直接套用整车固定停车再启动流程。
- 在单轮层面设计有界减速、零速确认及反向加速；协调另一轮输出，避免把该轮过零扩大为人为整车停顿。先核对电机控制器允许的过零时序、有效实测反馈与驱动限速/死区。
- 过渡过程限制前后速度，不超过当前比例目标；满杆优先避免残余前冲。不能为了保持“连续”绕过真实反转保护，也不承诺物理反转过程绝对没有瞬时零速。
- 停止/急停/失联立即清零且优先于斜坡；取消代次、超时保护、旧输入不得复活等约束保留。灯态跟随实际状态，不用灯态修改掩盖运动问题。
- 验证矩阵：前进/后退×左右转向、杆量往返、保持端点、快速回中、快速换边、显式停止、失联及陈旧/无效反馈。区分“无人工全车硬停”与必要的单轮物理过零。

## 2. APP触感反馈（本地完成）

- 遥控和扫描建图共用触感组件，跟随系统设置；设备不支持时保留视觉反馈，不强制振动。
- 前进/后退操作受理：一次轻反馈；反向先停、停止按钮：可区分的较强反馈。
- 摇杆回中和抵达左右端点：每次状态变化反馈一次，端点保持不连续振动。
- 参数加减、滑条松手确认：轻反馈；拖动过程不按每一帧触发。
- 禁用、拒绝及尚待自动模式接管确认的操作，不发“运动成功”触感。程序重组、地图刷新和状态轮询不得触发反馈。

## 3. 建图步骤共同布局（本地完成）

- 四步共用全局顶栏/步骤条/地图区域/底部操作区结构，保持全局标题、急停和设备状态位置。
- 取消建图固定左下，下一步/保存固定右下；上一步固定在下一步左侧，第一步无上一步时不移动下一步。统一按钮尺寸、颜色、间距、基线和触控区域。
- Step1保留左右参数/遥控侧栏；Step2/3使用同一布局网格容纳编辑工具，避免地图区域随页面改变大小或位置。停止按钮仅放在有运动控制的步骤，不改变后续提交、冻结或取消语义。

## 4. 地图视口与跨步继承（本地完成）

- 统一1–8倍、默认1倍、缩放锚点/拖动边界/复位入口及倍率显示。
- 共用图片适配与显示旋转基准；交接同一冻结底图，同时传递地图坐标中的视图中心和倍率。不要直接拷贝屏幕像素pan。
- 下一步、上一步与同会话返回保留所看位置和倍率；新建会话/换图/取消时按规则清理。
- 纯显示视角与实际地图编辑角度分开，不为视觉一致修改地图物理坐标、区域数据或机器人位姿。

## 5. 验收与交付（本地完成）

- 单轮过零与安全状态机单测，APP输入和触感事件次数回归，跨步骤投影/视口交接及按钮对齐检查。
- 同尺寸真实Compose截图：扫描、编辑、工作区、保存；展示1倍/放大状态与步骤往返效果。
- 分开报告离线通过、ROS联调和实机验证；触感与连续运动效果需要支持相应硬件的现场确认。未授权前不部署或操作机器人。

执行顺序：先确定连续转向控制方案并离线验证 → 共用建图布局与视口 → 加触感反馈 → 截图/构建/安全回归 → 实机验收。

## 最终结果（2026-10-24）

- 上一轮整车零速等待提前放行方案已撤回；新单轮过零与协调轮包络、比例速度上限、零速确认、停止/急停/失联优先控制已实现。回中时不能为保持直行分量而超出另一轮目标包络；高频重发不能突破时间斜坡。91项板端相关离线回归通过。
- 触感20项common测试（其中10项控制器、1项触感跨界）及6项原生UI测试通过；系统设置与真实触感强弱需在平板体验。
- 会话5测试、视口2测试通过；四步共同按钮/地图边界与2倍视角往返由离线Compose组件夹具验证。截图1600×966，底图为合成占据栅格，Step2–4使用生产组件的离线组合，未运行网络ViewModel流程。
- 生产APK与测试APK打包成功。未安装到平板、未更新板端、未操作机器人；现场电机过零及ROS链路仍未验收。
- 扩大core:model旧NMEA测试有8项失败（旧校验和数据、Android日志stub），本次针对性会话测试通过；其他既有GNSS/轨迹颜色限制保留记录。
