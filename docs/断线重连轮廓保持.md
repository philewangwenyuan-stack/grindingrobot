# 断线重连 footprint 保持

原因：`AppState.clearDeviceStatus()` 在断线/连接失败时清除了机器人几何；自动重连成功没有统一读取机器参数，只有 HomeViewModel 首次打开等页面入口读取。当前页面因此收到空 footprint，绘制逻辑回退为 APP 默认轮廓，直到再次应用机器参数。

修复：

- 断线继续清除姿态、任务实时状态、视频地址，保留同设备已确认的尺寸和 footprint。
- TcpManager 的连接成功回调统一只读查询底盘、机器几何及 RPP 参数，包括自动重连，不向板端写入 APP 默认或缓存参数。移除首页重复的首次读取。
- 所有连接入口先按 host/port 绑定参数缓存，切换主机或端口后清理旧参数，避免跨设备复用。
- 老协议或部分回复未包含有效 polygon 时，保留已确认的 footprint；收到有效新轮廓后替换。

缓存为本次 APP 进程的已确认值，不作为离线控制依据，不改变机器参数的临时/永久保存语义。工控机若重启丢失临时参数，重连读取到的新实际参数仍优先。
