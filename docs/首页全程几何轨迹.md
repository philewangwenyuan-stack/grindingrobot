# 首页全程几何轨迹

首页实际执行轨迹由 `TaskTrajectoryAccumulator` 构建，不再用最近500个位姿列表。
它只改变显示材料，不改变规划路径、板端数据、任务启动规则或运动指令。

`TaskTrajectoryGeometry.kt` 保存世界坐标中的磨盘中心。用包含全部已合并采样的角度走廊与单调半径约束，将近直线压缩到最大1厘米绝对误差，保留转弯、回头、颜色切换和断口。已完成部分是共享的不可变FloatArray块，活动块最多128顶点；128是单块大小，不是总量上限。原始数据参与构建后不逐条永久保存，复杂度取决于几何形状。

最新机器人位姿独立保存，不因轨迹简化而滞后；READY只更新图标，RUNNING/PAUSED记录轨迹。相同位姿复用快照。换任务、空闲或显式停止按原规则清理；断线、3秒以上上报间隔或无效位置断开路径，禁止跨缺失数据连线。物理参数晚到时先保留位姿，参数到齐后转换；之后的参数变化从新段开始，旧几何保留当时校准。

`TaskTrajectoryDrawing.kt` 将完成块的投影/原生Path缓存，当前块按版本更新。Fit、展示旋转、缩放和平移通过Canvas矩阵完成，不重复逐点变换。原有0.9米磨盘宽度用连续圆角笔画表示；只有孤立点显示单个轮廓，不对每个上报采样画圆。按时间顺序绘制，较新遍次在交叉处覆盖较早遍次。该形状表示执行轨迹，不是实际研磨面积或磨盘使能状态的测量。

“全程”指本次APP接收到的任务过程，不再淘汰早期路段。未增加APP重启后的回放补取或离线轨迹恢复。任意复杂曲线的完整几何仍可能比旧500点截断列表占用更多内存，不能做固定内存下降承诺。

验证：64项常规设备单测、4项Android原生绘图测试通过；性能测试另有504条有效对照记录。5万点/40行合成往复路径得到80顶点，开发机整批更新140.9224→6.2252ms、累计托管分配降低92.89%；Android12模拟器离屏手势重绘2.5916→1.4482ms。不是现场平板FPS或整页速度测量。完整数据、环境、源码哈希和原生输出图见 `artifacts/trajectory-geometry/收益与验证.md` 及同目录数据包。
